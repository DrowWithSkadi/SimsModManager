# Sims Mod Manager

Менеджер модов для The Sims 4. Перетаскиваешь в окно скачанные архивы, а он сам их распаковывает и раскладывает по папкам игры.

## Что умеет сейчас

- Находит папку игры (`Документы\Electronic Arts\The Sims 4`), в том числе если «Документы» лежат в OneDrive или папка игры названа на другом языке.
- Устанавливает моды из **ZIP, RAR, 7z**, а также отдельные файлы `.package` и `.ts4script`. Можно перетащить сразу много.
  - Каждый мод кладётся в свою папку `Mods\Название мода\`.
  - Скрипты всегда оказываются не глубже одной подпапки, иначе игра их не загружает.
  - Распаковываются и архивы внутри архивов, мусор (`readme.txt`, `__MACOSX`) пропускается.
  - Повторная установка того же архива обновляет мод, а не создаёт дубликат.
- Показывает список модов: поиск, фильтр, количество файлов, размер, есть ли скрипты.
- Включает и выключает моды (выключенные переносятся в папку `Mods (выключенные)` рядом с Mods, игра её не видит).
- Удаляет моды в корзину.
- Предупреждает, если моды или скрипты выключены в настройках игры, и включает их одной кнопкой.
- Очищает кэш миниатюр (`localthumbcache.package`).
- Находит моды, установленные вручную неправильно (скрипт слишком глубоко в подпапках).

## Скачать

На странице [Releases](../../releases) → «Тестовая сборка» скачайте **SimsModManager-win-Setup.exe** и запустите.
Программа установится, появится в «Пуске» и на рабочем столе, а новые версии будет предлагать сама
(Настройки → «Проверить обновления»). Без установки — архив **SimsModManager-win-Portable.zip**.

## Для разработки

- .NET 10, WPF, C#
- `src/SimsModManager.Core` — вся логика (без интерфейса), её проверяют тесты
- `src/SimsModManager.App` — окно программы (WPF, MVVM)
- `tests/SimsModManager.Tests` — тесты

Собрать exe: `dotnet publish src/SimsModManager.App -c Release -o publish`
